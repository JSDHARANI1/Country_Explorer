# 🌍 Country Explorer

A modern React-based web application that allows users to explore countries and view detailed information using the REST Countries API.

---

## 🚀 Features

* 🌐 View a list of all independent countries
* 🔍 Click on any country to see detailed information
* ⚡ Fast and responsive UI
* 🔄 Dynamic routing using React Router
* ⏳ Loading indicator for better user experience

---

## 🛠️ Tech Stack

* **Frontend:** React (Vite)
* **Styling:** Tailwind CSS
* **Routing:** React Router DOM
* **API:** REST Countries API

---

## 📦 Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/JSDHARANI1/Country_Explorer.git
```

2. Navigate to project folder:

```bash
cd Country_Explorer
```

3. Install dependencies:

```bash
npm install
```

4. Run the development server:

```bash
npm run dev
```
